## 问题逐条

### 1. Rex 中已关联的业主在 App 中不显示（高）

**原因**
- App 原来只在导入联系人时读一次 Rex，之后在 Rex 里改的业主关联不会同步过来。
- Rex 存的手机号带空格（如 `0401 999 088`），App 搜索时没有去掉空格，所以搜不到。

**修正**
- 服务器**每 60 秒**检查一次 Rex 的变更，把房产的业主关联同步到 App。另外每天全量核对一次，防止漏掉只改了关联的情况。
- 手机号匹配前统一格式：去掉空格，`+61` 和 `0` 开头视为同一个号码。
- 首页下拉可**手动刷新**。

**怎么验证**
1. 在 Rex 里把一个联系人关联为 16 Gager St 的业主。
2. 等 1–2 分钟，在 App 首页下拉刷新。
3. 打开 16 Gager St → OWNER 里能看到这个人。
4. 在 App 里输入他的手机号，空格写不写都能匹配到。

### 4. App 中添加的业主未写入 Rex（高）

**原因**
- App 新建的联系人没有写到 Rex，也没有在 Rex 里建立"业主"关联。
- 当时同步推送遇到部分地块房产会出错，App 里的修改没有到达服务器。这一点已在服务器端修复。

**修正**
- App 新建的联系人会在 Rex 里新建联系人，并关联为这套房产的 **Owner**。
- 联系人和房产下面显示同步状态：**Pending Rex / In Rex / Rex failed / Rex skipped**。
- **限制**：只有已经在 Rex 里的房产才能建立关联。不在 Rex 的房产（如 9 Boorman St），联系人照样写进 Rex，但不会自动在 Rex 里新建房产，App 显示 "Not in Rex yet"。

**怎么验证**（必须用 **16 Gager St**，这套在 Rex 里）
1. 打开 16 Gager St → **Edit record** → 填虚构姓名和 0491 570 156 → 保存。
2. 等 1–2 分钟，状态变为 **In Rex**。
3. 在 Rex 打开 16 Gager Street → Contacts，能看到这个人，角色是 Owner。

> 上次测试用的是 3 Feltwell St，它不在 Rex 里，所以关联被跳过。那条测试联系人（真实号码）已从 Rex 和 App 中清除。

### 7. OFI 界面无法使用（高）

**原因**：App 没有从 Rex 读取开放日（Open Home），所以列表是空的，页面上只剩转介卡片，看起来像卡在一个没有出口的页面。

**修正**
- 服务器从 Rex 导入挂牌的开放日（日期、开始时间、时长、时区）。
- OFI 页列出**今天**的开放日（地址、时间、签到人数）；今天没有时显示 "No open homes today" 和下一场。
- OFI 是底部标签页，用底部标签栏可以随时切回其他页面。从列表进入签到或签到名单后，可以返回列表。
- 删除了 "Hidden extra: long-press the logo…" 这一行。
- 转介请求（Referral requests）移到首页，只在有数据时显示。

**怎么验证**
1. 在 Rex 里给一个挂牌建一个**今天**的 Open Home。
2. 等 1–2 分钟，App 下拉刷新 → OFI 页能看到这一场，可以进入签到，再返回列表。

> 签到人数写回 Rex 的字段名还没有在 Rex 里确认，目前只在 App 里统计。

### 10. "Check in · OFI" 打开错误页（高）

**原因**：+ 菜单里这一项的跳转地址写错了。

**修正**
- 改为跳到 OFI 页面（有今天的开放日时可直接签到）。
- 任何找不到的页面都直接回到首页，**不再向中介显示原始路由错误**。

**怎么验证**：首页 → **+** → **Check in · OFI**，进入 OFI 页面，不出现 "Unmatched Route"。

### 8. My patch 找到 0 套房产（高）

**原因**
- 圈选计数只查了手机里的一小部分示例房产，而且坐标判断有误。
- Delfin Drive / Carnaby Street 一带当时手机里没有房产数据。

**修正**
- 画图时**实时显示**区域内的房产数，完成后列出区域内的全部房产。
- 服务器提供"区域内房产"查询，覆盖 Rex、Pricefinder 和 RP Data 的房产。
- 默认名称改为"区名 + 编号"（例如 "Sunnybank 1"），不再是 "Zone 0"。
- 按钮改名 **Save patch**：保存的片区只存在 AxleoCollect 里，**不写入 Rex**。
- 删掉了 App 里内置的 8MB 示例地址数据。现在地图和 patch 只显示 Rex 和市场数据（Pricefinder / RP Data）的房产。

**怎么验证**
1. 首页 → Market monitor → Edit patch → 在 Lister St 一带画一个区域。
2. 画的过程中计数变化；完成后能看到房产列表，默认名称是 "Sunnybank n"。

> 目前有测试数据的区：Sunnybank、Sunnybank Hills、Calamvale、Parkinson（约 2,200 套）。其他区（如 Macgregor）没有市场数据，显示 0 是正常的。

### 5. 房产详情：示例数据，无来源（高）

**原因**：页面显示的 4/2/2、615 m²、Lot 19 RP 123456 是写死的示例数据。

**修正**
- 删除示例数据。没有数据的字段显示 "—"。
- 已完成 RP Data 导入功能。房产页显示：房型、卧室/浴室/车位、土地/建筑面积、建成年份、用途、分区、地块（lot/plan）、最近成交（价格/日期/类型）、中介和经纪人、登记业主、成交历史。
- 底部注明 **"Source: RP Data · updated [日期]"**。

**目前的数据**
- **真实 RP Data 暂不导入**，要等 CoreLogic 许可确认（见下面"待回答的问题"）。
- 测试服务器上导入的是**按 RP Data 格式生成的测试数据**：4 个区约 2,200 套，业主名都以 **"(Test)"** 结尾，价格和日期是随机的，不是真实数据。

**还没有的**：估值、学校、可比成交。Ping 提供的 RP Data 导出文件里没有这些字段，需要 CoreLogic 的其他导出或 API。

### 6. "Open in Rex" 无反应（中）

**修正**
- 在 Rex 里的房产：按钮打开 `app.rexsoftware.com/properties/#tab=key_details&id=<Rex ID>`。
- 不在 Rex 的房产：按钮置灰，显示 **"Not in Rex yet"**。

**怎么验证**：16 Gager St → Open in Rex ↗ 打开 Rex 网页；9 Boorman St 显示 "Not in Rex yet"。

### 3. 无联系人时备注语音不可用；录音方式不一致（中）

**修正**
- 房产备注**不再需要联系人**，任何房产都能录语音或写文字。
- 录音方式统一为**点一下开始、再点一下停止**。Talk to me 翻译除外，仍是按住说话。
- 语音里识别到姓名和澳洲手机号时，弹出确认卡片，由中介确认后填入；没有识别到时直接保存备注。
- 修复了识别结果中出现 `<UNKNOWN>` 之类占位符的问题。
- **新增**：在 Rex 里的房产，App 里写的新备注会自动写进 Rex 房产的 Notes，正文末尾带 "— via AxleoCollect · 中介名"。不在 Rex 的房产显示 Rex skipped。

**怎么验证**
1. 9 Boorman St → NOTES → 点麦克风录一句不含姓名电话的话 → 再点停止 → 直接保存。
2. 16 Gager St → 写一条备注 → 1–2 分钟后状态变为 **In Rex**，Rex 房产页能看到这条备注。

### 2. "Add contact" 与 "Edit record" 重复（低）

**修正**：OWNER 区只保留一个按钮。没有业主时显示 **Add or link owner**，有业主时显示 **Edit record**。

### 9. "Share to AxleoCollect" 与 "New enquiry" 重复（低）

**修正**：+ 菜单只保留 **Add to-do / New enquiry / Check in · OFI**。从其他 App 分享到 AxleoCollect 的功能（手机分享菜单）保留。

## 待回答的问题（我们的答复）

**1. App 中新建的联系人写入 Rex 前是否需要审批？中介在哪里查看状态？**
目前**不需要审批**，保存后直接写入 Rex，1–2 分钟内完成。状态显示在联系人和房产页面：Pending Rex / In Rex / Rex failed / Rex skipped。合并联系人、改派等操作需要管理员在首页审批。如果需要"新建联系人也要审批"，可以加，请确认。

**2. Rex 多久同步到 App 一次？能否增加手动刷新？**
- Rex → 服务器：**每 60 秒**检查一次变更；业主关联另外每天全量核对一次。
- App → Rex：保存后立即排队，通常 1–2 分钟内写入。
- 手动刷新：**首页下拉**即可。

**3. 统一采用哪种录音方式？**
已统一为**点一下开始、再点一下停止**。理由：不用一直按着，边走边说更方便，也不会因为手指松开而中断。只有 Talk to me 翻译保留按住说话，因为它是对话式的。

**4. 没有联系人时，能否把文字备注保存到房产？**
**可以，已实现。** 房产备注不需要联系人；在 Rex 里的房产，备注还会同步写进 Rex。

**5. RP Data：CoreLogic 许可允许在 App 中显示哪些字段？**
需要向 CoreLogic 确认，这不是技术问题：
- 订阅条款是否允许把导出数据存进第三方系统（AxleoCollect 服务器）并在手机上显示；
- 业主姓名能否用于上门/电话联系（QLD 业主姓名不能用于直接营销）；
- 数据处理与隐私：服务器在悉尼；AI 功能也都在澳洲境内处理（AI 提取用 AWS Bedrock 悉尼的 Claude Haiku 4.5，语音识别用 Azure 澳洲东部）。

确认之前，测试环境只用测试数据。拿到许可后，先一键清除测试数据，再导入真实数据。

**6. "Teddy Chen" 是语音转文字错误还是保存错误？**
服务器上**没有 "Teddie Chan" 或 "Teddy Chen" 的记录**。说明当时这条联系人没有成功同步到服务器（当时的同步推送问题已修复），所以无法从日志判断是语音识别还是保存的问题。请重测时**手动输入**姓名：如果保存的和输入的不一致，就是保存问题；如果只在语音时出错，就是语音识别问题。

**7. Lisa Tran（Axleo Finance）的转介是真实数据还是测试数据？**
**测试数据**，来自开发用的演示数据，已从测试服务器移除。
