# Rex Capture · Web 工作台（交互原型）

Vue 3 + Element Plus + ECharts + Leaflet，所有数据都是前端模拟的，不连接 Rex。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build && npm run preview   # http://localhost:5180
```

演示要点：右上角切换登录身份，可在管理员、团队负责人、经纪人之间切换，菜单和数据范围会随之变化；Ctrl+K 打开全局搜索；点「驾驶舱」进入全屏大屏，按 F 全屏、Esc 返回。
